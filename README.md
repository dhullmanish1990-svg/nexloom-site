# NexLoom review site (static, GitHub Pages)

Plain HTML and CSS, no build step. `noindex` is set so search engines skip it while it is a review draft.

- Preview: open `index.html`, or run `python -m http.server 8000` here and visit http://localhost:8000.
- Contact address (Get in touch, Send feedback) is set in `index.html`.
- Publish: push this folder to a GitHub repo and turn on Pages (Settings, Pages, branch `main`, folder `/ (root)`). The page is public to anyone with the link.
